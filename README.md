# Dulshan Kalansuriya — Engineering Portfolio

Personal portfolio source owned and maintained by Dulshan Kalansuriya.

## Update this website
- Edit index.html for profile, education, experience and contact details.
- Edit projects.js for project descriptions and gallery captions.
- Replace images in this repository using the same filenames.
- Replace the CV files in this repository using the same filenames.
- Save changes on the main branch. GitHub Pages republishes the website.

## Publish
In repository Settings > Pages, choose Deploy from a branch, main, /(root), then Save.

Keep a local backup before changing files. Do not upload private diaries or full training reports; the website includes only selected portfolio materials.
